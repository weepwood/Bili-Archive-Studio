# Windows 客户端测试版 v0.4.0-test.1

采用 Tauri 2 + WebView2 封装当前本地归档阅读器，安装包自带 Node.js 24 运行时，使用时不必另装 Node。

## 测试
1. 安装 NSIS 安装包，从开始菜单启动 Bili Archive Studio。
2. 在独立窗口中测试首页、工作台、动态、SQLite 索引和媒体缓存。
3. 关闭后重新打开，确认数据保留。
4. 个人数据保存在 Windows 用户 Local AppData 应用目录，不会自动迁移旧版 archive-data。
5. **B 站采集仍需 Edge/Chrome 扩展**；本版不是自动采集完整版。

## 注意
- Windows x64，需要 Edge WebView2 Runtime。
- 本地服务仅监听 127.0.0.1:18765；目前只能同时运行一份。
- 可先备份并拷贝旧的 JSON 文件到客户端的数据目录，重启后重新索引。
- 不要分享登录凭证、archive.sqlite 或私人归档文件。
- 本版本为初次原生打包测试，重点检查启动失败、杀毒误报、数据目录、显示缩放。

## v0.4.1 登录关联与阅读器切换修复

### 修复内容
- 修复页面重复加载 `studio.js` 和重复 `openStudio` ID 引起的多层工作台、按钮无响应。
- 动态阅读页新增「退出阅读器」，点击进入管理工作台首页；工作台右上角「返回阅读器」返回动态列表。
- 首页、顶部导航和工作台新增「登录 / 关联账号」入口；首次没有归档账号时显示账号连接引导。
- 账号关联不读取密码或 Cookie：在 Chrome / Edge 的哔哩哔哩网页登录，打开客户端获取 8 位一次性连接码，输入浏览器扩展完成关联。
- 关联只传输当前 B 站账号 UID、昵称和头像 URL，保存到本地 `linked-account.json`；断开关联不会删除已归档数据。
- 账号关联完成**不代表动态已归档**；数据采集仍由浏览器扩展内的采集面板执行。

### 账号连接步骤
1. 启动 Windows 客户端，打开「登录 / 关联账号」。
2. 在 Edge / Chrome 打开并登录 [哔哩哔哩](https://www.bilibili.com/)。
3. 从同版 GitHub Release 下载 `Bili-Archive-Studio-browser-extension.zip` 并解压。打开浏览器扩展管理页，开启开发者模式，选择**解压目录中的 extension 文件夹**加载。
4. 回到客户端点击「生成 8 位连接码」。在浏览器扩展弹窗中输入连接码，点击「关联当前 B 站账号」。
5. 客户端自动显示已关联账号；点击扩展的「打开动态采集面板」，继续把动态保存到本地归档目录。

> 连接码只在本机保留 5 分钟；请勿截图分享。当前 Windows 客户端使用的数据目录与旧的网页版可能不同，浏览器采集结果不会自动跨目录搬运。
